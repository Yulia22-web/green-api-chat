# MAX Chat — тестовое задание

Небольшой чат для мессенджера MAX на React. Умеет отправлять и получать
текстовые сообщения через GREEN-API. Ничего лишнего — только то, что просили
в ТЗ.

## Что использовал

- React 18 (Vite в качестве сборщика, чтобы не возиться с webpack)
- Чистый CSS, без препроцессоров и UI-библиотек
- Никаких state-менеджеров — на таком объёме они не нужны, хватило
  useState + кастомного хука

## Как запустить

Нужен Node.js 18+ и npm.

```bash
npm install
npm run dev
```

Открыть http://localhost:5173

Сборка продакшен-версии:

```bash
npm run build
```

## Что нужно для работы

Сначала нужно получить данные от GREEN-API:

1. Зайти на green-api.com и зарегистрироваться
2. Создать инстанс в личном кабинете
3. Авторизовать его через QR-код (сканируешь приложением MAX)
4. Скопировать оттуда `idInstance` и `apiTokenInstance`

Дальше в приложении:

- вводишь эти два значения
- вводишь номер собеседника в формате `79999999999` (без плюса и пробелов)
- жмёшь «Начать чат»

После этого можно писать. Сообщение уходит в MAX, ответ приходит обратно
в течение пары секунд.

## Как устроено

Вся работа с API лежит в `src/hooks/useGreenApi.js`. Компоненты в
`components/` занимаются только отображением и не знают про fetch —
так тестировать и править проще.

Отправка — обычный POST на `sendMessage`.

Получение — polling. Раз в 3 секунды дергаю `receiveNotification`,
обрабатываю, если что-то пришло, и сразу удаляю через `deleteNotification`.
Без удаления уведомление приходит повторно, поэтому шаг обязательный.

Изначально думал про WebSocket, но в ТЗ явно указан HTTP API, так что
остановился на polling. Для тестового это нормально, хотя в продакшене
я бы всё-таки смотрел в сторону вебсокетов — 3 секунды задержки не всегда
ок.

## Структура

```
src/
├── components/
│   ├── AuthForm.jsx      — форма входа, три поля
│   ├── ChatWindow.jsx    — шапка чата
│   ├── MessageList.jsx   — список сообщений + автопрокрутка
│   └── MessageInput.jsx  — поле ввода снизу
├── hooks/
│   └── useGreenApi.js    — вся логика с API
├── utils/
│   └── api.js            — три функции под эндпоинты GREEN-API
├── App.jsx
└── main.jsx
```

## Что знаю, что можно доработать

- Polling вместо вебсокетов — работает, но не идеально
- Ошибки сейчас просто летят в консоль, никаких тостов — для тестового
  норм, для продакшена нет
- При перезагрузке страницы всё сбрасывается, credentials не сохраняю
  в localStorage (специально, чтобы не хранить токен в открытом виде)
- Нет отправки файлов и медиа — по ТЗ и не требовалось
